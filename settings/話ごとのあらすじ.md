# 話ごとのあらすじ（時を刻まない男）

引き継ぎメモから移した、各話の詳しい記録。続きを書く前に、直前の数話ぶんだけ読めばいい。

## 1〜60話・幕間01〜08
- 遊園地の夜（6〜12話）：原作どおり青子が草十郎を狩る→青子人形→取引→地下で湊が青子をかばって死ぬ→蘇生がバレる→有珠の月の油・割れる卵・偽の月→大月蝕→草十郎が卵の呪いで背中に大怪我（映画準拠）。この夜、湊は四回死んだ
- 13〜14話：草十郎は屋敷で療養（有珠はシーツの件でブチ切れ、三日話しかけない宣言→14話で崩れる）。湊が青子と有珠に正体を話す
- 15〜25話の日常（遊園地の夜から二週間ほど。十二月の初め〜中旬）：
  - 湊の上着は紺のダッフルコート（青子と買った）。青子は焦げた袖を継いだ茶色のコートを使い続ける
  - 青子は毎日店に通う（見張り名目、梅昆布茶）。湊は屋敷用に梅昆布茶の缶をこっそり渡している
  - 有珠は店用のポットと紅茶を置いている（急須は禁止）。店と二階の物置に有珠と青子の結界（ガラス玉）
  - 二階の物置（天井まで木箱三十〜四十）＝魔術的に莫大な価値。有珠が黒い革の目録をつけている（湊の話の聞き書きも。「あの人が最後のひとりにならないための本」）
  - 開けた箱：元禄（番付・最初の煙管・茶屋の娘の櫛）、明治横浜（石鹸・オルゴール＝有珠に貸している・湊の明治の写真・おはじき＝青子に）、正暦（大江山の鬼の角＝絶対に出さない、瓢箪、河童の詫び証文＝帳場）、玉手箱（煙が半分残る、湊にだけ無害、絶対に開けない）
  - 九百年前の銅鏡は有珠が屋敷で預かっている。小判は青子が換金（「借り」）
  - 草十郎は学校に復帰。湊の店とまっどべあでバイト。期末試験は赤点回避
  - 四人の写真（煙草屋のおばあさんが撮影、青子が湊の袖をつまんでいる）が帳場の柱時計の横に貼ってある
  - 26話（火曜）：青子が鳶丸に現像代を払う。鳶丸は写真が店に貼ってあると草十郎から聞いていて「そのうち参考書買いに行く」。物置から舌切り雀の「大きいほうのつづら」（草十郎が選んだ。四百年ほど前、峠道で拾った。中に小さい化け物多数）。火の玉が一つ逃げ、青子の髪をかばった湊が右手のひらに火傷（一週間ほど痛む）。草十郎が素手で捕まえ、有珠が瓶に入れて屋敷に持ち帰る（部屋の明かり代わり。草十郎になついている）。つづらは物置の一番下、鬼の角・玉手箱より手前
  - 27話（水曜）：鳶丸が定例をさぼって来店。日本史の参考書（三百円）、湊に元禄を習う。写真の袖を見て青子をからかう。外で湊に「あいつはひとりで抱えるのをやめた」「蒼崎がまたひとりで抱えだしたら言え」。湊の手の火傷も草十郎の背中も「ストーブ／風邪じゃない」と見抜いているが、聞かない。河童の証文は店の飾りだと思っている。青子は去年、ひとりで抱えて倒れかけたとき鳶丸にひっぱたかれた（仮）。湊は「誰とも半歩離れてる」と言われる
  - 28話（木曜）：初雪（積もらない）。青子が包帯を替える（有珠より下手）。湊は火傷以来パンだけ→青子が店の奥の台所で雑炊（お粥寄り）を作る。冷蔵庫は酒と漬物と卵だけ。店の奥は台所と四畳半（仮）。「誰かにご飯作ってもらったことある？」「ある」で終わり、青子は深追いしない。相合傘で屋敷まで送る、青子が半歩寄る。明日も晩ご飯を作る約束。有珠は火の玉の瓶を二階の窓際に置いた
  - 29話（金曜夜）：晩ご飯の途中で青子が網の異変（北のはずれの古い神社の裏の雑木林、仮）に気づき「来ないで」と出ていく。湊は追う（人払い素通り）。人形五体（公園の夜と同型、青子の指の動きを読んで避けるよう仕込まれている）。湊が「今」「右」「上」と声だけで撃つタイミングを出し、三体撃破。最後の一体が湊を狙う→湊は今回初めて避けようとして間に合わず一回死ぬ。戻った体に人形の腕が挟まり、青子が大きな一撃（赤い影に耐える描写）で撃破、木が二本倒れる。青子は脇腹にかすり傷、コートの袖がまた裂ける。湊のダッフルコートの胸に穴→捨てずに青子が継ぐことに（明日裁縫箱を持ってくる）。人形の破片から外国の強い煙草のにおい（橙子の匂わせ。湊はどこかで嗅いだ気がするが思い出せない、誰にも言っていない）
  - 30話（土曜）：青子がコートの胸の穴を少し青い紺の端布で継ぐ（「今度穴開けたら、もう継がない」）。夜十一時、人形五体が店を襲う（腕が刃→鉤に変わっている。湊を引っかけて止めるため。昨夜の戦いを見て湊を狙ってきた）。湊は死ねないと決めて、シャッター用の樫の鉤棒一本で全滅させる（関節の継ぎ目を狙う、狭い通路を使う、同士討ち、投擲）。五体目は煙草屋を狙い、湊が棒を投げて止める。おばあさんの部屋のカーテンが揺れた（見られたか不明）。湊はふくらはぎを深くえぐられ（一か月残る）、頬に切り傷。死んでいないので治らない。店のガラス戸が割れ、結界のガラス玉が割れて屋敷に伝わり、草十郎→青子・有珠が駆けつける。「こんなに戦えたの！？」「聞かれなかった」。湊が戦わなかった理由：戦うと長くなる、死んだほうが早かった。戦の中にいた年数は数えていない（百年では短いとユーザー指摘。帝の兵が始まり、望んで行ったことはない）。草十郎「おれのとは違う。覚えたものを覚えたとおりに使っている」。有珠は青子の脇腹の嘘（生徒会で転んだ）も29話の神社の件も知った（草十郎が青子の独り言を聞いていた）。人形の残骸は有珠が屋敷で調べる
  - 31話（日曜）：煙草屋のおばあさんがほうじ茶・おにぎり・亡夫の湿布と、店の前に落ちていた人形の硝子玉を「ビー玉かしら」と持ってくる（見たかどうかは湊にはわからない。湊は聞かない）。青子は記憶を消すか迷うが、湊が「そういうことにしといてくれ」で消さない。有珠の調べ：作り手はとても腕のいい人形師、硝子玉の目は見たものを遠くへ送る（仮）＝神社も昨夜も見られていた。有珠が屋敷に来るよう提案→湊は断る（店と物置を空けない、誰かの家には住まない）。結界のガラス玉を倍に、毎晩青子が魔力を足す。ロビンが店の夜番に（ストーブ横のタオル、朝はパンの耳）。有珠は目録に「時任湊、継ぎのために死ななかった」と書くと言う。湊は人形の煙草のにおいが、数年前に古い本を一冊買っていった眼鏡の女と同じだった気がしかける（顔も本の題名も思い出せない）
  - 32話（月曜）：【ユーザー指定で方針変更】湊は夜だけ久遠寺邸に泊まり、昼は古本屋に通う。理由は「自分が店にいると向かい（煙草屋）に迷惑がかかる」（「住むんじゃない、泊まるだけ」）。荷物は風呂敷ひとつ。部屋は草十郎の隣の客間、青子の部屋の廊下の向かい。屋敷では煙草・梅昆布茶禁止→夜、門の外の石垣で湊は煙草、青子は梅昆布茶（「共犯」）。青子「来てくれてよかった。夜中に何回も店の明かりを窓から見ちゃう」。ガラス戸は駅前のガラス屋が直した。ロビンは店でひとり夜番（パンの耳二枚、湯たんぽ、電気スタンド点けっぱなし）。鳶丸は湊の怪我を見て「またストーブか」「ストーブじゃない」、黙って鞄を持つ
  - 33話（火曜朝）：ロビンは店でひと晩ひとりで寂しがっていた（パンの耳に手をつけず）。湊が夜明け前に迎えに行き、コートのポケットに入れて連れ帰る（「意外とあったかいッス。煙草くさいけど」）。有珠も一晩眠れず階段で待っていた。ロビンの夜番はやめ、店の結界に触れたら有珠の部屋の鈴が鳴るよう組みなおす。屋敷の朝ご飯は一番早く起きる草十郎の担当（土鍋の米、大根が大きい味噌汁）。有珠は朝も紅茶。青子は寝坊してセーター裏返し・寝癖のまま台所で湊と鉢合わせ。湊「寝癖ついてても、蒼崎は蒼崎だ」
  - 34話（火曜〜水曜明け方）：店の結界に有珠の鈴（帳場の柱、写真の下）。日没後に湊以外が触れると屋敷の有珠の部屋の鈴が鳴る。有珠の晩ご飯は紅茶とジャムパンとゆで卵。夜、草十郎が湊の客間へ（壁を二回叩く合図）。草十郎「前は死ぬのが怖くなかった、今は少し怖い（屋敷のご飯、蒼崎が怒る、店、鳶丸）」湊「それでいい。怖いと避ける」。棒の使い方を教えてと頼まれ断る（静希は体が勝手に動くほうが強い）。「いつか時任が何を覚えているか少しずつ聞きたい」。明け方四時に鈴→全員で駆けつけたら新聞配達だった（湊は祖父の代から新聞をとっている）。有珠が紙（新聞・郵便・回覧板）を通すよう修正。青子はテレビ欄を見たい。草十郎が自分で大根を小さく切ろうと気づく
  - 35話（水曜）：【ユーザー指定】湊は料理がめちゃくちゃうまい（船の炊事係ほか、千年のどこかで覚えた。自分ひとりのためにはほぼ作らない）。手の火傷はほぼ治った（薄いガーゼ一枚）。有珠の料理を避けるため湊が晩ご飯を作る。食材は湊が自腹。献立：鰤大根、鯖の味噌煮、ほうれん草のおひたし、だし巻き卵、浅蜊の味噌汁、牛蒡と豚肉の金平、土鍋ご飯。食後に有珠にスコーン（ロンドン行きの船の英国人船長仕込み、百年前の味）→有珠「古い味。小さいころどこかで食べた気がする」。青子「作れるなら最初から言いなさいよ！……聞かれなかった、でしょ」。ロビンは湊を「料理長」と呼ぶ。草十郎はご飯四杯。後片づけで青子「私の雑炊どうだった」湊「蒼崎のは俺に食わせるためだった。俺のはうまいだけだ」。青子が大根の煮方を教わる約束
  - 36話（木曜〜金曜朝）：湊が青子に大根の煮方を教える（面取りで手首を押さえる→ロビンが冷やかす。青子の大根は醤油が少し多い「蒼崎の味がする」）。草十郎が鳶丸（相談役）から隣町の水族館の切符を二枚もらう（鳶丸経由は仮）。屋敷に置いてもらっているお返しに青子と有珠へ。草十郎は「おれが行ったら返すことにならない」と留守番。湊のアドバイス「そのまま渡せ」→草十郎「聞かれる前に言う」。有珠は水族館に行ったことがない。日曜に決定。湊は店。湊は人形の作り手が屋敷の空く日を狙うかもと思うが言わず、日曜は店を早めに閉めて坂の上を気にするつもり。青子は湊に土産を買う約束（「蒼崎がいいと思ったもの」）
  - 37話（日曜）：青子と有珠が水族館へ（有珠は鞄に紅茶の葉、青子の袖の継ぎは二か所）。草十郎が屋敷で留守番。昼、橙子が屋敷を訪ね草十郎と話す（描写は草十郎の伝聞のみ：屋敷のポットで紅茶、山の話、眼鏡を外す、「少し似ている」と言われた。名前は言わず草十郎も聞かず）。午後二時、橙子が時任書房へ（名乗らない）。眼鏡あり：柔らかい口調、数年前に来た客だと自分から言う、草十郎のことを話す、和綴じの古本（題名不明、八百円）を買う、柱の写真の青子を見て「こんな顔、するんだ」。眼鏡を外す（「ごめんね。眼鏡、外してもいいかしら？」）→口調が乾いた「〜だ」調、帳場のマッチで外国の煙草、携帯灰皿。神社と土曜の夜を人形越しに見ていたと明かす。「終わらない体」「完成品」。なぜ死ねば消える傷を抱えているのか→湊「死ぬと、怒る人がいるので」→写真を見て「……そうか」。「欲しいものは手に入れる。予告だ」→湊「封印なら三百年前にされた。百年で出た。閉じこめた人はとっくに死んでた」→橙子が本気で笑う「いいな、君」「また来る。今度は本を買いにじゃなく」。坂の下で眼鏡をかけなおして駅へ。煙草屋のおばあさんが後ろ姿を見ていた。湊は店を閉めて屋敷へ、草十郎と石段で話す。帰ってきた青子と有珠（青子は大きな紙袋、有珠はぬいぐるみ）に湊が自分から「あった。中で話す」。湊はまだ女が青子の姉だと知らない
  - 38話（日曜夜）：湊が自分から全部話す。青子「……姉貴よ。蒼崎橙子」。跡取りになるはずだったのは橙子、祖父が青子を選んで家を出た。網・結界が反応しなかったのは蒼崎の人間だから（原作準拠の説明）。目的は青子の継いだものを取り返すこと＋湊（完成品、人形の材料）。青子は自分のせいと謝る。有珠「決着の日が近い」（原作：帰宅した二人は橙子の来襲を知り決戦が近いと悟る）。有珠のマンボウのぬいぐるみ「やさしい顔なのに傷だらけ。あなたに似ている。眠そうなところも」。青子の土産：真鍮の透かし彫りの魚の栞（尾びれに青いガラス、群れで一匹だけ反対向きにゆっくり回っていた魚）→湊はコートの内ポケット（胸の継ぎの裏）に。湊「何十年でも来ればいい。来たらそのたびに断る」青子「そのとき私もいる。何十年でもそばで一緒に断ってあげる。だから死なないで断りなさい」湊「……ああ」。屋敷の居間に暖炉（仮）
  - 39話（月曜）：青子の地図。網の礎は五つ、三つは削られ残り二つ（東の川べり・西の外れ。位置は仮。「残り二つの支柱で決戦」はあらすじより）。両方同時なら青子と有珠で二手に。青子は湊と草十郎に屋敷にいろと命じ、湊は「蒼崎が正しい」と了承（草十郎は不満）。鳶丸「何かあんのか」湊「ある」「今はひとりじゃない」。湊は物置から槍の穂先（いつの戦のものか覚えていない）を出し、シャッターの樫の鉤棒を柄にするつもり。青子に「済まないなら死ぬ。でも逃げるためでも盾になるためでもなく、勝つために死ぬ。一回死ぬたびに相手の手をひとつ潰す」→青子「勝つために開けた穴なら何回でも継ぐ、千回でも。絶対に勝って、戻ってきて、死んだ回数を全部数えて私に言いなさい。一回ずつ怒ってあげる」。青子は「全部終わったら」言いたいことがある（終わってから言う。「もし、私が」の続きとも重なる）
  - 40話（木曜夜・決戦）：東西の礎に同時に敵、青子は西・有珠は東へ。槍は鉤棒の鉤を外して穂先を針金と革紐で固定（三日かけて研いだ）。十時半、焦げたロビンが屋敷へ「東の川べりで眼鏡の女が待ってた、地面に光る文字（ルーン）、マイ天使の夜が出す前に壊された、目が動かなくなった（魔眼）、大きな狼」→草十郎が東へ救出に。直後に有珠の部屋の鈴→店に人形二十体と『棺』（黒い漆の箱に蜘蛛のような腕、蓋にびっしりルーン。湊を封じるための、百年では壊れない棺）。棺の腕が煙草屋の二階へ→湊は栞と携帯灰皿を居間のテーブルに置いて屋敷を出る。【ガチ不死戦】1回目：六本の鉤に吊られ棺へ運ばれる→（死体でも棺に入れられるので死ぬだけでは逃げられない）鉤の食いこんだ肉を穂先で自分で切り離し、最後に首を切って死ぬ→即座に戻るので鉤には何も残らない。2回目：背骨を折らせて、のしかかった人形の下から戻って立つ。3回目：棺の腕に叩き潰される瞬間に穂先を肘裏の要の文字へ→腕停止。4回目：三体に貫かれ腕を奥まで引きこむ→戻った肉が三本の腕を咥えこむ（29話と同じ）→まとめて首を刎ねる。5回目：頭を握り潰され、戻って指の関節を落とす。6回目：棺の腕に右腕を握られ口の前へ→自分の右腕を肘の上で断ち切り、腕だけが棺に吸いこまれる→失血で死んで戻る→棺は中身が入ったはずが空で術式が軋む。7回目：三体に腹・左腕・顎をやられながら蓋中央の文字の渦に穂先→棺炎上。計七回、声に出して数えた。服はぼろ布、胸の継ぎの布だけ残りポケットへ。ガラス戸また割れる。ハイライトは焼失。煙草屋二階のカーテンが開いていた（聞かない）。草十郎が有珠を負ぶって戻る（有珠は生きている、ケープぼろぼろ）。有珠「何回」湊「七回」有珠「青子に怒られるわね」。西は静かすぎる→湊は「数えた回数を言いに行く」と西へ走る。草十郎は有珠を屋敷に置いて追う
