# 文体メモ（時を刻まない男）

- 三人称。湊の近くから書くのが基本。場面によって青子・有珠側に移ってもよい
- 段落は短め。会話文の前後は空行
- 読点（、）を打ちすぎない。「湊は、少し考えた。」ではなく「湊は少し考えた。」くらいでいい。息継ぎが要るところだけ打つ（16話までは多め。17話から減らす）
- 余韻を狙った詩的な締めはほどほどに
- 短文の連発をしない（ユーザー指摘・30話）。「〜した。〜した。〜した。」と一文一段落で刻まず、つながる動作は接続でつないで一文にする。段落は二〜四文くらいを基本にして、一行だけの段落は決め所だけに使う。会話の前後の空行は今までどおり
- 【AI臭さ対策・ユーザー指摘（52話）】体言止め・短い言い切りの連発を減らす。「看板の下の四人。」のような名詞だけの一行、「〜だった。〜だった。」の連続を避け、文末を「〜ている」「〜る」「〜のだろう」「〜らしい」なども混ぜて揺らす。読点は息継ぎに要るところだけ（「湊は、」「それから、」の後に打たない）
- 決まり文句を使い回さない：「湊は少し考えた」「何も言わなかった」「たぶん、両方だった」「〜と、湊は思った」「それだけだった」「嘘はなるべくつかない」の多用禁止
- 有珠の目録は物の記録だけ（品名・年代・出どころ・扱いの注意）。誰が何をした、のような所感や出来事は書かない（ユーザー指摘）。出来事は有珠の十年日記のほうに書いている設定（53話）
- 【AI臭さ対策・ユーザー指摘（62話）】「湊は、〜」「青子は、〜」のような『主語＋は、』の書き出しを大幅に減らす。主語のあとに読点を打たない（「湊は帳場で」）、主語を「が」で受ける、主語を省く、時・場所・動作から書き出す、などで文頭を散らす。書いたあとに『は、』の数を数えて確認する

- 【ユーザー指摘・冬木編のあと】何でもかんでも『千年』『千回』につなげない。梅昆布茶を出しすぎない（出すのは要所だけ）
